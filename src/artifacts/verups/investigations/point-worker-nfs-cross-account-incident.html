A routine CI/CD deploy of point-worker-deployment on the Verup-side staging cluster (stg-ex) failed its rollout after five minutes. The proximate cause was a stuck NFS mount — but the real story is that a Terraform apply on a completely different AWS account, a full day earlier, silently severed a cross-account dependency nobody had documented anywhere in code.

03 · Root Causes
Both introduced by the same Terraform apply

Both the missing route and the revoked security group rule were out-of-band ("ClickOps") exceptions that had never been captured in Terraform code. A routine apply on the Point-STG side reconciled state to match declared code — correctly, by its own logic — and silently deleted both.

06 · Lessons
What this incident actually teaches
ClickOps exceptions are invisible to Terraform drift detection by design

A rule or route added outside of Terraform has no representation in state. The next apply on that resource treats it purely as unwanted drift and removes it — with zero signal that a live, working dependency on the other side of an account boundary is about to break. The apply itself was correct relative to its own declared code; the danger lives entirely in what the code didn't know about.

Blast radius extended past the resource anyone thought about

The route table change targeted a subnet, not a single instance. That subnet also hosts 3 EKS worker nodes (point-api, point-worker, point-app) in the Point-STG cluster itself — meaning any outbound traffic from those nodes toward 172.19.0.0/16 broke the same way, independent of HULFT entirely.

Two clusters, same name, different account — a triage trap

Two separate GitHub repositories each run a CI workflow literally named point-worker, deploying to an EKS cluster literally named point — one targets Point-STG (471112755246), the other targets verup-stg (520411743393). The only reliable way to tell which account a given failed run actually touched was to match the CD-runner instance ID quoted in the CI log against describe-instances in each candidate account.
