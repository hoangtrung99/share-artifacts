HTTPS-only Origin: Forward Host Header

BB-1512 // CyberZeal compliance // CloudFront → ALB encryption

Khi chuyển origin_protocol_policy sang https-only, CloudFront validate chung chi SSL cua ALB origin. Chung chi *.backseat-service.com khong match voi ALB DNS name. Giai phap ban dau (Route53 custom domain) cung that bai vi RFC 6125 wildcard chi match 1 DNS label. Giai phap cuoi cung: forward Host header de CloudFront validate cert theo Host thay vi origin domain.

1 — Van De (Hai Tang)
Van De 1 ALB DNS khong match cert
CloudFront ket noi toi ALB bang DNS name tu dong. Cert *.backseat-service.com khong match *.elb.amazonaws.com.
Origin domain: point-alb-xxx.ap-northeast-1.elb.amazonaws.com ALB cert SAN: *.backseat-service.com Match? KHONG → 502 Bad Gateway
Van De 2 Route53 custom domain cung that bai
Giai phap ban dau: tao origin-alb.dev-ex.backseat-service.com tro toi ALB. Nhung cert *.backseat-service.com van khong match vi day la 2-level subdomain.
Origin domain: origin-alb.dev-ex.backseat-service.com Wildcard cert: *.backseat-service.com Match? KHONG → * chi match 1 label
2 — RFC 6125: Wildcard Matching
RFC 6125 § 6.4.3 Quy tac Wildcard
Theo RFC 6125 (va RFC 2818), ky tu * trong wildcard certificate chi match dung 1 DNS label (phan giua hai dau cham). No khong match across dot boundaries.
CertDomainMatch?Ly do
*.backseat-service.com dev-ex.backseat-service.com Yes * = dev-ex (1 label)
*.backseat-service.com bo-dev-ex.backseat-service.com Yes * = bo-dev-ex (1 label)
*.backseat-service.com origin-alb.dev-ex.backseat-service.com No * khong match origin-alb.dev-ex (2 labels, co dau cham)
*.backseat-service.com a.b.backseat-service.com No * khong match a.b (2 labels)
AWS Docs: "CloudFront verifies that the certificate was issued by a trusted CA and that the domain name in the certificate matches the domain name that you specified for Origin Domain Name, or the value of the Host header if you configured CloudFront to forward the Host header to the origin."
3 — Cac Phuong An
Da Chon Forward Host Header
Giu nguyen domain_name = ALB DNS name. Them Host vao forwarded_values.headers cho tat ca ALB behaviors. CloudFront validate cert theo Host header value thay vi origin domain.
  • Host = dev-ex.backseat-service.com → match cert *.backseat-service.com
  • Khong can tao Route53 record moi
  • Khong can bien alb_origin_domain moi
  • ALB dung path-based routing → Host header khong anh huong routing
  • Cache key impact negligible (ALB behaviors serve dynamic content)
  • Rollback don gian: xoa Host khoi headers, chuyen protocol ve http-only
Loai Bo Route53 Alias Record
Tao origin-alb.{env}.backseat-service.com tro toi ALB. That bai vi RFC 6125: day la 2-level subdomain.
  • origin-alb.dev-ex.backseat-service.com = 2 DNS labels
  • Cert *.backseat-service.com chi match 1 label
  • Can tao cert *.dev-ex.backseat-service.com rieng → khong kha thi
  • Them Route53 records + variables → phuc tap hon

Cach Giai Phap Hoat Dong
1
Client gui request toi dev-ex.backseat-service.com → Host header = dev-ex.backseat-service.com
2
CloudFront forward Host header toi ALB origin (vi Host nam trong forwarded_values.headers)
3
CloudFront dung Host value lam SNI trong TLS handshake thay vi ALB DNS name. SNI = dev-ex.backseat-service.com
4
ALB trinh cert *.backseat-service.com. CloudFront validate: dev-ex.backseat-service.com match *.backseat-service.com → TLS OK

8 — Ke Hoach Rollback
Rollback don gian — chi dao nguoc 3 thay doi
Vi khong tao tai nguyen moi (Route53, variables), rollback chi can revert code:
# cloudfront.tf (ca customer va admin) origin_protocol_policy = "http-only" # tu "https-only" origin_ssl_protocols = ["TLSv1", "TLSv1.1", "TLSv1.2"] # Xoa "Host" khoi forwarded_values.headers: # /app/*: headers = ["user-agent"] # bo "Host" # /api/*: xoa dong headers # khong co truoc do # /admin/*: xoa dong headers # khong co truoc do # cloudfront_policy.tf (websocket) items = [Sec-WebSocket-Key, ...] # bo "Host"
Uu diem rollback: Khong can xoa Route53 record, khong can restore variables hay data sources. Chi revert protocol policy va xoa Host header → 1 commit duy nhat.
