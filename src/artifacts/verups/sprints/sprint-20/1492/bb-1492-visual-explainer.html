Cách Terraform tham chiếu cert này
# frontend-customer/tfvars/dev-ex.tfvars:4 # (stg-ex, admin dev-ex, admin stg-ex cũng giống) cloudfront_certificate = "*.backseat-service.com" # frontend-customer/data.tf:1-4 # (frontend-admin/.../data.tf cũng giống) data "aws_acm_certificate" "this" { provider = aws.us # us-east-1 domain = var.cloudfront_certificate # "*.backseat-service.com" statuses = ["ISSUED"] } # frontend-customer/cloudfront.tf:16-20 viewer_certificate { acm_certificate_arn = data.aws_acm_certificate.this.arn # → trỏ tới cert Cybertrust imported }

Terraform không quản lý lifecycle của cert này — chỉ lookup theo domain rồi lấy ARN. Nếu cert bị xoá khỏi ACM, terraform plan sẽ fail vì data source không tìm thấy.

7 Rủi ro liên quan đến chứng chỉ
!
Cert Cybertrust hết hạn 2026-10-29
Imported cert không auto-renew. Cần manual re-import trước ngày này. Nếu quên → CloudFront mất HTTPS viewer cert → toàn bộ site không truy cập được.
!
Terraform plan fail nếu cert bị xoá
data "aws_acm_certificate" lookup sẽ fail nếu cert Cybertrust bị xoá khỏi ACM. Lúc đó không ai có thể terraform plan cho CloudFront components.
!
Không có audit trail
Không ai biết ai import cert Cybertrust, khi nào import, và quy trình renew ra sao. Không nằm trong terraform state → không có history.
?
DEV for_cloudfront cert bất thường
Cert for_cloudfront ở DEV us-east-1 không thấy trên AWS dù enable_certificate_for_cloudfront = true. Có thể bị xoá thủ công hoặc terraform state lệch với thực tế.
