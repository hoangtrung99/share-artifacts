01 Nguyên Nhân Gốc

Terraform tạo ACL mới (chỉ có default DENY ALL) và associate vào subnet trong cùng 1 API call. Các allow rules chỉ được tạo ở bước sau. Khi chạy từ bastion nằm trong VPC, khoảng trống giữa 2 bước cắt đứt mọi kết nối mạng — Terraform không bao giờ chạy đến bước tạo rules.

03 "The Gap" — Khoảng Trống Chết Chóc

Terraform thực hiện tuần tự: tạo ACL → associate → tạo rules. Giữa bước 2 và 3 là "the gap".

1
Tạo ACL mới
aws_network_acl.public[0] + private[0]
ACL chỉ có default rule * = DENY ALL
↓
2
Associate ACL → 6 subnets
ReplaceNetworkAclAssociation
Thay thế default NACL (allow all) bằng NACL mới (deny all)
↓
⚠
THE GAP — Bastion mất mạng tại đây!
NACL mới = DENY ALL. Chưa có rule nào cho phép traffic. Bastion không thể gọi AWS API để chạy bước tiếp theo.
✘ không bao giờ đến ↓
3
Tạo allow rules (KHÔNG BAO GIỜ ĐƯỢC CHẠY)
Rule 100: HTTPS 443  |  Rule 200: VPC CIDR  |  Rule 300: Ephemeral...
⚠
Vấn đề thiết kế Terraform: Resource aws_network_acl nhận subnet_ids trực tiếp — tạo ACL + associate trong cùng 1 bước. aws_network_acl_rule là resource riêng, chỉ chạy sau. Không có cách nào đảo thứ tự mà không sửa module code.

Recovery Procedure — Khi bị lockout
  1. Mở 2 SSM session song song trước khi apply (session dự phòng)
  2. terraform state pull > backup.tfstate — backup state
  3. Chạy terraform apply — sẽ bị stuck
  4. Từ session dự phòng hoặc AWS Console: thêm rule 50 ALLOW ALL vào ACL mới
  5. force-unlock state lock
  6. state push errored.tfstate
  7. Xóa ACL rules trùng bằng AWS CLI
  8. terraform apply lại để hoàn thành
⚠
Quy trình này mất 1+ giờ và rủi ro cao. Chỉ dùng khi TUYỆT ĐỐI không thể apply từ local.

08 Quy Tắc Cho Mọi Môi Trường

KHÔNG BAO GIỜ apply NACL từ máy nằm trong VPC đang thay đổi

Áp dụng cho DEV, STG, PRD. Luôn apply từ máy local hoặc CI/CD nằm ngoài VPC. Kết nối AWS API qua internet không bị ảnh hưởng bởi NACL thay đổi bên trong VPC.

An toàn
  • ✔ Local machine + AWS credentials
  • ✔ CI/CD pipeline (GitHub Actions, etc.)
  • ✔ Máy ở VPC khác hoặc account khác
Nguy hiểm
  • ✘ Bastion host trong cùng VPC
  • ✘ EC2 instance trong cùng VPC
  • ✘ EKS pod trong cùng VPC
