BB-1845: AWS Athena (WAF Log) Infrastructure

WAF access log query service cho Verup project

Scope: INFRA only Env: dev-ex / stg-ex Refs: BB-1845
01 Overview

Mục tiêu

Tạo hạ tầng AWS Athena để query WAF logs (tất cả access logs bao gồm blocked, allowed, counted) từ S3. Worker (server-side, ticket riêng) sẽ dùng Athena tổng hợp dữ liệu theo giờ, lưu vào MySQL, hiển thị trên BO admin panel.

Port từ Coinbook (UNYO-1074) sang Verup với naming convention khác và cải tiến kiến trúc: dùng IRSA thay vì worker node role, đổi tên table cho chính xác hơn.

06 WAF Rules & DEV/STG Testing

Lưu ý: country_restrict không fire trên DEV/STG

Trên DEV/STG, is_public = false nên rule block_except_allow_ipv4 (priority 0) hoạt động. Rule này block tất cả IP không nằm trong allowlist trước khi country_restrict (priority 1) được evaluate.

flowchart TD
    REQ["Incoming Request"] --> P0{"Priority 0\nblock_except_allow_ipv4\n(is_public=false)"}
    P0 -->|"IP NOT in allowlist"| BLOCK0["BLOCK\nterminatingruleid =\nblock_exepct_allow_ipv4"]
    P0 -->|"IP in allowlist\n(team members)"| P1{"Priority 1\ncountry_restrict\nallow: JP,CN,HK,US"}
    P1 -->|"Country NOT in list\n(e.g. VN without VPN)"| BLOCK1["BLOCK\nterminatingruleid =\ncountry_restrict"]
    P1 -->|"Country in list\n(JP/US via VPN)"| REST["Priority 2-12\nBPO, GMO, rate limits..."]
    REST --> P13["Priority 13\nallow_all_ipv4 ALLOW"]

    BLOCK0 -.->|"Logged in WAF"| S3["S3 WAF Logs"]
    BLOCK1 -.->|"Logged in WAF"| S3
    P13 -.->|"Logged in WAF"| S3

Kết quả: Trên DEV/STG, hầu hết requests bị block bởi block_except_allow_ipv4 (priority 0), không phải country_restrict. Athena query với terminatingruleid = 'country_restrict' sẽ trả về ít hoặc không có data.
Loại testDEV/STGPRDGiải thích
Query tất cả WAF logs OK OK Mọi request đều ghi vào S3
Query action = 'BLOCK' OK OK Có data từ block_except_allow_ipv4
Query terminatingruleid = 'country_restrict' Limited OK DEV/STG: rule 0 block trước. PRD: is_public=true nên rule 0 không tồn tại
Khi PRD triển khai (is_public = true): Rule block_except_allow_ipv4 sẽ không tồn tại → country_restrict trở thành rule đầu tiên evaluate → Athena query cho country_restrict sẽ có đầy đủ data.
