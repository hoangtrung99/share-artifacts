Verup Platform — Tổng quan kiến trúc

Verup là sáp nhập 2 hệ thống: Exchange (sàn crypto cũ) và Point (nền tảng điểm/thưởng). Codebase thống nhất absorb code Exchange, hạ tầng, và frontend, giữ Point làm reference cho kiến trúc đích. Migration Verup → Point đang diễn ra — Phase 3 (apply DEV) xong; Phase 4 (apply STG) đang chờ EKS ladder, Aurora cutover, và CTO phê duyệt.

3 · Luồng Worker / SQS / Redis

Workers là event-driven, không phải cron-driven. Mỗi worker class có SQS queue riêng (auto-created). Message dạng SNS-wrapped. Execution gate bởi Redis lock với TTL = 0 (không bao giờ tự expire).

Quyết định designChi tiếtBằng chứng
Redis lock TTL = 0LockParams.WORKER có lockExpireSeconds = 0. Lock không tự expire — phụ thuộc finally unlock. Rủi ro: pod crash = lock kẹt cần can thiệp thủ công.RedisManager.java
SQS auto-createQueue tạo on-demand per worker class, tên <env>-<workerClassName>, attach SNS topic policy.SqsManager.java
Không có dead-letter queueKhông DLQ — message fail chỉ retry theo Glue built-in (max 1) hoặc visibility timeout (120s).SqsCallback.java
Không event busKhông Kafka, RabbitMQ, Spring Cloud Stream. Chỉ SNS/SQS cho job distribution + Redis pub/sub cho WebSocket price broadcast.Application.java

Lớp 2 — Application code (dual datasource, không tự route)

// Read-only master query
@Transactional(readOnly = true, transactionManager = CommonConstants.MASTER_TRANSACTION_MANAGER)
public User findById(Long id) { ... }

// Write to master
@Transactional(transactionManager = CommonConstants.MASTER_TRANSACTION_MANAGER, rollbackFor = Exception.class)
public void save(User user) { ... }

// Archive to historical (Redshift)
@Transactional(transactionManager = "historicalJpaTransactionManager")
public void archive() { ... }

Schema management: ddl-auto: validate (không auto-create). Flyway quản lý schema qua docker/flyway-*. Integration server thêm MyBatis-Plus (MasterMybatisConfig.java) và Glue historical access (GlueHistoricalDataSourceConfig.java); point server không có.

6 · ETL Pipeline (Glue)

Ownership 2 repo: bs-glue-jobs sở hữu artefacts (PySpark script, configs, ops scripts). bs-exchange-infra/terraform/components/glue-etl/ sở hữu AWS resources (S3, KMS, IAM, Glue jobs, triggers, alarms).

Gotcha đặt tên

Tên bucket prefix aurora-to-redshift- là historical và misleading. Glue job write Parquet lên S3 — không write trực tiếp Redshift. Redshift Spectrum đọc data S3 qua external tables.

Batches (5 Glue job slots, hằng ngày 02:05 JST)

Sync modes: FULL (không bookmark) · INCREMENTAL (bookmark keyset pagination) · BACKFILL (date window) · FULL FILL (tables có bookmark key include id). Bookmark lưu JSON trong S3 meta bucket.

10 · Luồng Request End-to-End

API requests (/api/v1/*) vào point-api pods, check Redis cache trước, rồi Aurora khi cache miss. App requests (/app/v1/*) vào point-app pods trực tiếp. Async operations publish lên SQS qua SNS, consume bởi point-worker pods với Redis locking.

11 · Quyết định kỹ thuật chính

#Quyết địnhTradeoff
1Monolithic multi-module build1 repo build 6 deployables từ shared point-common. Đơn giản cho team nhỏ, coupling cao.
2Không service mesh / FeignInter-service = plain RestTemplate → k8s DNS. Đơn giản, nhưng không circuit breaker / retry ở transport layer.
3SNS/SQS cho job distributionWorkers event-driven, không cron-driven. Queue auto-created per worker class.
4Redis lock TTL = 0Lock không tự expire. Rủi ro: pod crash = lock kẹt. Phụ thuộc finally unlock.
5Explicit dual transaction managersKhông tự route read/write. Dev chọn master vs historical mỗi method. Max explicitness.
6ddl-auto: validate + FlywaySchema quản lý bởi Flyway migrations, Spring chỉ validate. Không auto-DDL.
7Không GitOpsDirect GitHub Actions → SSM kubectl. Đơn giản, nhưng không reconciliation loop.
8Backend deploy qua SSMEKS API private. Deploy qua point-cd-runner EC2 thay vì kubectl trực tiếp từ CI.
9Glue → S3 Parquet, KHÔNG Redshift trực tiếpRedshift Spectrum đọc S3 externally. Tên bucket aurora-to-redshift- misleading.
10Frontend: static export + S3/CloudFrontKhông SSR — Next.js output: 'export' / Vue CLI dist. Đơn giản, rẻ.
