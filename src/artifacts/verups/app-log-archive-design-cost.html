Consideration 1

Audit is separate. CloudTrail and SSM Session Manager deliver natively to the existing audit-logs.bs-point-<env> bucket (no Firehose). This pipeline only raises that bucket's lifecycle expiration. RDS log archival was dropped — it duplicated data already covered natively.

Consideration 2

S3 storage class (cost-saving)

The app-logs lifecycle is STANDARD → 30d → GLACIER_IR → expire. Firehose writes large objects (~40 MB per flush), far above the GLACIER_IR 128 KB minimum, so Instant Retrieval is the sweet spot: ~5× cheaper than STANDARD, still instant reads for incident debugging.

Why audit-logs stays STANDARD: that bucket is dominated by tiny native objects (CloudTrail / SSM, mostly <128 KB). GLACIER_IR bills a 128 KB minimum per object plus a transition request — for small objects it raises cost. STANDARD wins there.

GLACIER_IR minimum storage duration is 90 days — safe here since retention ≥ 365 days.

At the measured volumes, the buffer is time-triggered every 15 minutes (daily volume < 128 MB per 15 min), producing ~40 MB objects — comfortably above the GLACIER_IR minimum. Compression stays UNCOMPRESSED at Firehose because the CloudWatch→Firehose payload is already gzip level 6; setting GZIP would double-compress for no gain.

Monitoring: a delivery-error log group /aws/kinesisfirehose/app-log captures failures, plus Firehose CloudWatch metrics DeliveryToS3.Success and DeliveryToS3.DataFreshness (alarm-able for staleness).

Key takeaway. Even at 7 years with GLACIER_IR, the app-log archive is only tens of dollars a month per environment (≈ $54/mo at 3.8 GB/day, ≈ $71/mo at 5 GB/day). Against a total infra bill in the thousands/mo (EKS + Aurora + Redshift + NAT), it is a rounding error — well under 1–3%. Storage class is the lever that keeps it there: GLACIER_IR is ~78% cheaper than STANDARD across a 7-year horizon.

Reference measured volumes (app ≈ 96% of total): dev-ex 3.8 · stg-ex 6.85 · point-dev 2.28 · point-stg 1.92 GB/day. prd not yet measured. Model is steady-state storage + ingest; excludes the tiny retrieval cost, which applies only when logs are read back.
