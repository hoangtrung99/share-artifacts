Problem Statement

BB-1566 — ADMIN
Zero Rate-Based Rules
Admin WebACL has no rate-limiting on any endpoint. Authentication, registration, and password-reset paths are completely unprotected against brute-force attacks.
CyberZeal 6.1 audit FAIL — rate-based protection required for compliance.
BB-1541 — CUSTOMER
Rate Limits Too Broad
Current limits are blanket rules: /api/ = 30,000/5min, /app/ = 80,000/5min per IP. These cover all paths equally, leaving authentication endpoints unprotected against targeted attacks.
OTP brute-force feasible: 6-digit code crackable in ~62 seconds at 80,000 req/5min.
